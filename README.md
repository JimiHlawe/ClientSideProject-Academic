# D&J Personal Credit Card

A client-side web application for managing personal credit card accounts.

## Features

- **User Authentication**: Login and registration system for secure access
- **Dashboard**: View credit card details, balances, and account information
- **Charges**: Track and manage credit card transactions
- **Actions**: Perform card operations like locking/unlocking
- **Profile Management**: Update user profile information
- **Responsive Design**: Mobile-friendly interface with hamburger menu

## Technologies

- **HTML5**: Page structure and content
- **CSS3**: Styling with media queries for responsive design
- **JavaScript (ES6 Modules)**: Client-side logic and interactivity
- **Local Storage**: Data persistence in the browser

## Project Structure

```
├── HTML/           # HTML pages (login, register, dashboard, etc.)
├── css/            # Stylesheets for each page
├── js/             # JavaScript modules and classes
│   └── classes/    # User, CreditCard, and StorageHandler classes
├── images/         # Background images and card graphics
└── extra/          # Additional resources
```

## Getting Started

1. Clone the repository
2. Open `HTML/login.html` in a web browser
3. Register a new account or use existing credentials
4. Navigate through the dashboard to manage your card

## Pages

- **login.html**: User login page
- **register.html**: New user registration
- **dashboard.html**: Main dashboard with card overview
- **charges.html**: Transaction history
- **actions.html**: Card management operations
- **profile.html**: User profile settings

## Note

This is an academic project for learning client-side web development. All data is stored locally in the browser using localStorage.
